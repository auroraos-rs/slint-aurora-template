# Slint app template for Aurora OS (maybe Sailfish OS)

Шаблон приложения для ОС Аврора с использованием UI фреймворка [slint](https://slint.dev).

## Зависимости для сборки

- [Aurora PSDK](https://developer.auroraos.ru/doc/sdk/psdk)
- [cross-rs](https://github.com/cross-rs/cross)
- [cargo-generate](https://github.com/cargo-generate/cargo-generate)

## Использование шаблона

- `cargo generate --git https://github.com/auroraos-rs/slint_aurora_template`
